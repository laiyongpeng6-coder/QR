# FastQrScan 需求/功能文档概要

## 应用概述
**FastQrScan** 是一款集成了二维码/条形码扫描、生成、历史记录管理、商品比价以及 AI 个性化二维码生成功能的现代化移动端应用。该应用以 Kotlin 和 Jetpack Compose 为基础构建，使用 Hilt 进行依赖注入，并采用模块化架构以实现功能解耦。

---

## 核心功能模块

### 1. 扫描模块 (feature:scanner)
- **实时扫描：** 使用 ML Kit 或 CameraX 实现实时的二维码和条形码扫描功能。
- **状态管理：** 管理扫描的不同状态，例如正在扫描、检测到结果、缺少摄像头权限等。
- **内容分类：** 自动识别和分类扫描的内容（如 URL 链接、Wi-Fi 配置、电话号码、电子邮件、联系人/vCard 以及纯文本等）。
- **设备反馈：** 扫描成功时触发设备的震动反馈（如果设置中启用）。
- **结果自动保存：** 检测到的扫描结果会自动记录并保存至应用的本地历史记录数据库。
- **自动跳转：** 支持检测到链接时根据用户偏好设置直接跳转到默认浏览器。

### 2. 生成模块 (feature:generator)
- **多类型二维码生成：** 支持用户通过输入内容生成不同类型的二维码，如：
  - 纯文本 (Plain Text)
  - 网址 (URL)
  - Wi-Fi 网络配置
  - 联系人 (Contact / vCard)
  - 电话 (Phone)
  - 社交媒体 (Social Media)
- **传统条码生成：** 支持生成主流商品/物流条码，包括：
  - EAN-13, EAN-8
  - UPC-A
  - Code 128
- **验证与容错：** 在生成前根据选择的类型进行格式验证及容量检查，如果格式不对或超长则提示错误。
- **记录保存：** 成功生成的条码或二维码自动归档到历史记录。

### 3. 历史记录模块 (feature:history)
- **记录展示与过滤：** 提供通过不同 Tab（扫描历史、生成历史）查看过往记录的功能。
- **搜索功能：** 支持对记录进行关键字搜索。
- **记录操作：** 提供记录的收藏标记功能、删除功能以及删除后的“撤销”恢复功能。

### 4. AI 美化工作台 (feature:ai-workspace)
- **个性化生成：** 提供高级二维码美化功能（例如改变二维码前景色、背景色、点阵形状等）。
- **实时预览：** 在输入内容或调整外观配置时实时重新生成并预览二维码。
- **（商业化/未来规划）：** 提示未来可能会提供基于订阅 (Pro) 的渐变色、AI 模板能力。

### 5. 商品比价查询 (feature:product-lookup)
- **条码查询：** 用户扫描商品条码后可以触发商品信息的在线查询，调用外部接口或数据库读取商品详情（ProductInfo）。
- **状态反馈：** 在查询时提供加载中、查询成功以及查询失败原因的展示。
- **（商业化/未来规划）：** 未来可能会添加高级的比价功能作为付费点。

### 6. 新手引导 (feature:onboarding)
- **应用指引介绍：** 为新用户提供详细的 4 页式滑动图文并茂的使用教程，帮助用户快速了解核心功能：
  1. **高速扫描：** 介绍如何使用自动变焦功能快速扫描各类二维码和条形码。
  2. **创建与分享：** 指引用户如何快速为 WiFi、联系人、网址等生成自定义的专属二维码。
  3. **AI 个性化美化：** 展示如何使用内置的 AI 工作台将普通二维码转变为精美的艺术作品。
  4. **历史与比价：** 介绍应用如何自动保存扫描记录，并支持线上商品信息的快速比价。
- **状态持久化与跳转逻辑：** 当用户点击“跳过”或在最后一页点击“开始使用”完成指引流程后，应用将通过本地存储（DataStore）持久化记录状态，确保在下次启动时直接跳过引导，平滑进入应用主界面。
